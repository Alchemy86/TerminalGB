## Why it moved

This page would still be true with no agent in the world, which is exactly the test
[`docs/where-things-live.md`](../where-things-live.md) applies: a fact about the game is
AtlasGB's to document; a fact about what our agent did with it is not. **The other half — the
rates our solver achieved, the starter line that cannot pass, and the links that carry it —
was already at [AgentGB's `docs/agent/misty.md`](https://github.com/Alchemy86/AgentGB/tree/main/docs/agent/misty.md)**
and is unaffected by this move.
